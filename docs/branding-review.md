# Public naming and branding review

Review date: 2026-09-26

Public working name: **FlightMargin**

Fallback if later clearance requires a change: **ReserveLight**

Practical collision screening found no obvious direct competing software
identity for FlightMargin. This is not formal legal or trademark clearance,
and the project does not claim trademark registration or ownership through
this review.

FlightMargin uses the OpenAI and Codex names only where needed to describe
compatibility with the user's existing Codex CLI. It does not use OpenAI logos,
the Blossom, OpenAI Sans, or copy that implies partnership, certification,
approval, or endorsement.

The following disclaimer remains required in the application and public
documentation:

> Unofficial community tool. Not affiliated with or endorsed by OpenAI.

The application identity is FlightMargin; descriptive OpenAI/Codex references
must remain secondary. A later name change to ReserveLight would require a new
collision review and a deliberate bundle/package migration.
